## Story 16: SDOM Spec + Pydantic Models + Serializer

**Objective**: Define the Spatial Document Object Model (SDOM) as pydantic models and implement the HTML→SDOM serializer using Crawl4AI.

**Files to create:**
```
src/parousia/spatial/
  __init__.py              # Package init, version
  sdom_models.py           # Pydantic models for the SDOM schema
  serializer.py            # HTML → SDOM via Crawl4AI
tests/
  test_spatial_serializer.py
  fixtures/
    sample_page.html       # A realistic HTML page for testing
    login_page.html        # A page with a login form
    search_results.html    # A search results page
```

**What to build:**

1. **`sdom_models.py`** — Pydantic models matching the SDOM spec:
   - `InteractiveElement`: id (str), type (enum: link/button/input/select/checkbox/radio/textarea), label (Optional[str]), text (Optional[str]), role (Optional[str]), attributes (dict with href, input_type, placeholder, checked, selected, disabled, required), rect (Optional[Rect] with x, y, width, height)
   - `ContentSection`: heading (Optional[str]), level (Optional[int] 1-4), text (str), images (list of {alt, src}), links (list of {id, text, href})
   - `Form`: id (str), action (Optional[str]), method (Optional[str]), fields (list[str] — IDs of interactive elements), submit_id (Optional[str])
   - `Navigation`: main_nav (list of {text, href, id}), breadcrumbs (list[str])
   - `Context`: cookies_set (bool), session_active (bool), authenticated_as (Optional[str]), content_type (enum: article/search_results/product/form/dashboard/error/login/generic)
   - `SdomMeta`: url (str), status (int), title (str), loaded_at (str)
   - `SDOM`: meta (SdomMeta), interactive (list[InteractiveElement]), content (list[ContentSection]), forms (list[Form]), navigation (Navigation), context (Context)

2. **`serializer.py`** — `SpatialSerializer` class:
   - `__init__(crawl4ai_config: dict | None = None)` — configure Crawl4AI with optional overrides
   - `to_sdom(html: str, url: str, status: int = 200) -> SDOM` — the main pipeline:
     a. Parse HTML with Crawl4AI's `AsyncWebCrawler` or sync `Crawler`
     b. Extract interactive elements: find all `<a>`, `<button>`, `<input>`, `<select>`, `<textarea>`, `[role="checkbox"]`, `[role="radio"]`
     c. Assign short volatile IDs: first input = `i1`, second = `i2`, first button = `b1`, etc.
     d. Filter out invisible/disabled elements (display:none, visibility:hidden, aria-hidden, disabled)
     e. Build content sections grouped by heading hierarchy (H1-H4)
     f. Detect forms: group fields + submit buttons by `<form>` parent or proximity
     g. Detect navigation: `<nav>` elements, breadcrumbs
     h. Classify page type from content signals (search form → search_results, login form → login, etc.)
   - `_assign_ids(elements: list) -> list` — ID assignment with prefix convention
   - `_truncate_text(text: str, max_chars: int) -> str` — truncation with `…`
   - `_detect_page_type(sdom: SDOM) -> str` — content type classifier
   - `estimate_tokens(sdom: SDOM) -> int` — rough token count (chars/4)
   - Truncation rules enforced: interactive[].text ≤ 120, content[].text ≤ 500, interactive[] total ≤ 200

3. **`__init__.py`**:
   ```python
   """Spatial browsing subsystem for Parousia Guard.
   Phase 3: Gives AI agents "native digital sight" — browser-aware
   spatial architecture with token-lean SDOM, per-agent Chromium profiles,
   and declarative MCP tools.
   """
   __version__ = "0.3.0"
   ```

**Verification:**
- `test_sdom_serialization_basic`: HTML fixture with links, inputs, buttons → SDOM with correct IDs (l1, i1, b1)
- `test_sdom_serialization_id_convention`: 3 links + 2 inputs → IDs l1,l2,l3,i1,i2
- `test_sdom_serialization_truncation`: Long text (>120 chars) in button → truncated with `…`

## Story 17: Browser Pool Manager

**Objective**: Manage per-agent Chromium instances with persistent profiles, health checks, idle timeouts, and lock-based concurrency control.

**Files to create:**
```
src/parousia/spatial/
  browser_pool.py          # BrowserPoolManager class
tests/
  test_browser_pool.py
```

**What to build:**

`BrowserPoolManager` class:
- `__init__(config: SpatialConfig)` — reads chromium_path, profile_dir, idle_timeout_seconds, max_instances, launch_args
- `get_browser(agent_id: str) -> BrowserInstance` — returns a ready browser:
  a. Check `profile.lock` — if locked, raise `ProfileInUseError`
  b. Create profile dir if missing: `/var/lib/parousia/browsers/{agent_id}/`
  c. Launch Chromium via Playwright: `playwright.chromium.launch_persistent_context(user_data_dir=profile_dir, args=launch_args, headless=True)`
  d. Health check: navigate to `about:blank`, verify CDP responsive (3s timeout)
  e. On failure: kill, retry up to 3 times, then raise `BrowserUnavailableError`
  f. Record launch time for idle tracking
- `release_browser(agent_id: str)` — mark as idle, start idle timer
- `_idle_cleanup()` — background task: close browsers idle > idle_timeout_seconds. Preserves profile dir (cookies/sessions survive).
- `shutdown_all()` — graceful close all browsers. Called on process exit.
- `status() -> dict` — returns: { agent_id: { "state": "active"|"idle"|"dead", "profile_size_mb": float, "idle_seconds": int } }
- `cleanup_profile(agent_id: str)` — remove profile dir (use with caution)

`BrowserInstance` dataclass:
- `agent_id: str`
- `browser: playwright.sync_api.Browser`
- `context: playwright.sync_api.BrowserContext`
- `page: playwright.sync_api.Page`
- `profile_dir: str`
- `launched_at: float`
- `last_used_at: float`
- `is_alive() -> bool` — check CDP connection

Lock file format (`profile.lock`):
```
pid:12345
agent:hermes
since:2026-06-08T10:00:00
```
Stale locks (PID not running) are auto-cleared on next `get_browser()` call.

**Verification:**
- `test_launch_browser`: get_browser("hermes") → returns BrowserInstance with alive page
- `test_profile_creation`: First get_browser → profile dir created at /tmp/test_browsers/hermes/
- `test_profile_persistence`: Launch, set cookie via JS, close, relaunch → cookie still present
- `test_agent_isolation`: get_browser("hermes") + get_browser("claude") → different profile dirs, different pages
- `test_concurrent_lock`: get_browser("hermes") twice → second call raises ProfileInUseError
- `test_health_check_retry`: Mock CDP failure → retries 3 times, then raises BrowserUnavailableError
- `test_idle_timeout`: Launch, release, wait idle_timeout → browser is closed, profile dir preserved
- `test_stale_lock_cleanup`: Write lock file with dead PID → get_browser() clears it and proceeds
- `test_max_instances`: Launch max_instances + 1 → raises error on overflow
- `test_shutdown_all`: Launch 2 browsers, shutdown_all → both closed
- `test_status`: Launch 2 agents → status() returns correct states and profile sizes
- `test_cleanup_profile`: cleanup_profile("hermes") → profile dir removed

**Target: 12+ unit tests**

**Note:** Tests use `/tmp/test_browsers/` via `SpatialConfig(profile_dir="/tmp/test_browsers/")`. Use Playwright's `chromium.launch_persistent_context()` not `chromium.launch()` — persistent context is what preserves cookies/sessions across invocations.

## Story 18: Spatial MCP Tools — Browse, Interact, Extract

**Objective**: Implement the three spatial MCP tools and wire them into the existing MCP server on port 8081.

**Files to create:**
```
src/parousia/spatial/
  tools.py                 # Tool schemas + SpatialToolHandlers
tests/
  test_spatial_tools.py
```

**What to build:**

1. **`tools.py`** — following the exact pattern of `src/parousia/temporal/tools.py`:

   Tool schemas (dict format matching existing `ALL_TEMPORAL_SCHEMAS`):
   - `browse_to_schema()` — url (required, string), timeout_ms (default 30000), extract_mode (enum: standard/content_only/interactive_only)
   - `interact_schema()` — id (required, string), action (required, enum: click/type/scroll_into_view/select/check/uncheck/hover/press), text (optional), timeout_ms (default 10000)
   - `extract_page_state_schema()` — mode (enum: full/changes/context_only, default: full)

   `SpatialToolHandlers` class:
   - `__init__(config: ParousiaConfig, browser_pool: BrowserPoolManager, serializer: SpatialSerializer)`
   - `dispatch(name: str, arguments: dict, agent_id: str) -> str` — route to handler, return JSON
   
   Handlers:
   - `_handle_browse_to(args, agent_id)`: 
     a. Get browser from pool: `browser = self.pool.get_browser(agent_id)`
     b. Navigate: `browser.page.goto(url, timeout=timeout_ms)`
     c. Wait for load: `browser.page.wait_for_load_state("networkidle")`
     d. Get HTML: `html = browser.page.content()`
     e. Serialize: `sdom = self.serializer.to_sdom(html, browser.page.url, status=200)`
     f. Return: `{navigated: true, sdom: sdom.model_dump(), token_estimate: ..., ...}`
   
   - `_handle_interact(args, agent_id)`:
     a. Get browser
     b. Resolve element: find the SDOM ID in the current page. Use Playwright selectors built from element attributes (prefer `[data-sdom-id="{id}"]` if we inject data attributes, or resolve from the last SDOM's element map)
     c. Execute action: `page.click()`, `page.fill()`, `page.select_option()`, etc.
     d. Check for navigation: if URL changed, get new page content, run through serializer
     e. Return: `{action_performed: true, page_changed: bool, new_url: ..., sdom: ...}`
   
   - `_handle_extract_page_state(args, agent_id)`:
     a. Get browser
     b. Extract markdown from current page content using Crawl4AI's markdown generator
     c. Return: `{extracted: true, url: ..., markdown: ..., context: ..., ...}`

   `ALL_SPATIAL_SCHEMAS = [browse_to_schema(), interact_schema(), extract_page_state_schema()]`

2. **Wire into MCP server** (`src/parousia/guard/mcp_server.py`):
   - Import `ALL_SPATIAL_SCHEMAS, SpatialToolHandlers`
   - In `_build_server()`: create `SpatialConfig` from config, create `BrowserPoolManager`, create `SpatialToolHandlers`
   - In `handle_list_tools()`: append spatial schemas to tools list
   - In `handle_call_tool()`: add spatial dispatch after temporal dispatch:
     ```python
     if name in ("browse_to", "interact", "extract_page_state"):
         agent_id = _resolve_agent_id(config, arguments)
         result = spatial_handlers.dispatch(name, arguments, agent_id)
         return [TextContent(type="text", text=result)]
     ```

**Verification:**
- `test_browse_to_schema_valid`: Schema has correct required fields
- `test_interact_schema_valid`: All 8 action types in enum
- `test_extract_page_state_schema_valid`: Three mode options
- `test_spatial_handlers_dispatch_unknown`: Unknown tool → error JSON
- `test_browse_to_local`: Start local HTTP server with fixture HTML, browse_to → SDOM in response
- `test_interact_click_navigation`: Local page with link, interact click → page_changed=true, new_url set
- `test_interact_type_input`: Local page with input, interact type "hello" → value set
- `test_extract_page_state_markdown`: Local page → extract_page_state → markdown contains page content
- `test_agent_isolation`: Two agents browse different pages → different SDOMs, no cross-contamination
- `test_browser_unavailable_error`: Browser pool down → browse_to returns error JSON

**Target: 10+ tests**

## Story 19: Config + CLI Integration

**Objective**: Add `SpatialConfig` to the Parousia config model and create CLI subcommands for spatial setup, status, and validation.

**Files to create/modify:**
```
src/parousia/config.py                    # MODIFY: add SpatialConfig
src/parousia/cli/
  spatial.py                              # CREATE: spatial CLI commands
tests/
  test_cli_spatial.py                     # CREATE
```

**What to build:**

1. **`config.py`** — New pydantic models:
   ```python
   class Crawl4aiConfig(BaseModel):
       word_count_threshold: int = 200
       exclude_tags: list[str] = ["nav", "footer", "aside", "script", "style"]
       exclude_selectors: list[str] = [".cookie-banner", ".ad-container", "#sidebar"]
       timeout_ms: int = 15000

   class SpatialConfig(BaseModel):
       enabled: bool = True
       chromium_path: str = "/usr/bin/chromium-browser"
       profile_dir: str = "/var/lib/parousia/browsers"
       idle_timeout_seconds: int = 300
       max_instances: int = 10
       launch_args: list[str] = ["--no-sandbox", "--disable-dev-shm-usage", "--disable-gpu", "--headless=new"]
       crawl4ai: Crawl4aiConfig = Field(default_factory=Crawl4aiConfig)
   ```
   Add `spatial: SpatialConfig = Field(default_factory=SpatialConfig)` to `ParousiaConfig`.

2. **`cli/spatial.py`** — CLI subcommands (following `cli/temporal.py` pattern):
   - `parousia spatial setup` — install deps: `pip install playwright crawl4ai browser-use && playwright install chromium`
   - `parousia spatial status` — show: enabled, chromium path, active instances, profile sizes, idle browsers
   - `parousia spatial validate` — check: chromium exists, crawl4ai importable, launch test page, verify SDOM
   - `parousia spatial cleanup` — remove idle profiles older than N days, purge session data

3. **Wire into `cli/main.py`** — add spatial subcommand group.

**Verification:**
